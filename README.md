## 🤝 AWN — Full-Stack Volunteer Networking Platform

**Graduation Project — Grade: A+**

AWN is a **full-stack, natively bilingual English/Arabic volunteer networking platform** connecting volunteers with organizations through a public user portal and a data-rich administrative dashboard.

### 🏗️ Architecture

```text
                    ┌─────────────────────┐
                    │     Next.js App     │
                    │   React + Tailwind   │
                    └──────────┬──────────┘
                               │
                               │ Axios
                               ▼
                    ┌─────────────────────┐
                    │   Express.js API    │
                    │   90+ REST Endpoints│
                    └──────────┬──────────┘
                               │
                    ┌──────────┴──────────┐
                    │                     │
                    ▼                     ▼
              ┌───────────┐        ┌────────────┐
              │  MySQL    │        │ Cloudinary │
              │ Database  │        │   Media    │
              └───────────┘        └────────────┘
```

### ⚡ Key Features

* 🌍 Native **English / Arabic bilingual interface**
* 📱 Responsive design across **20+ pages**
* 🎨 Modern UI built with **Next.js, Tailwind CSS & Framer Motion**
* 🌓 Light / dark theme support
* 🔐 JWT-based authentication
* 🛡️ Role-Based Access Control (**RBAC**)
* 🔌 **90+ RESTful API endpoints**
* 📊 **5 interactive Chart.js dashboards**
* 👥 Volunteer, company, and event management
* 📈 Administrative data visualization
* ☁️ Cloudinary-based media management
* 🔄 Axios client-server communication
