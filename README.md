## 🌍 Bilingual Architecture

AWN was designed to support both English and Arabic users.

```text
             AWN
              │
       ┌──────┴──────┐
       │             │
   🇬🇧 English    🇪🇬 Arabic
       │             │
       ▼             ▼
     LTR             RTL
```

The interface adapts between **LTR and RTL layouts**, allowing the application to provide a native experience for both languages.
